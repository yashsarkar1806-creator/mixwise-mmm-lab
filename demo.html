Marketing mix model lab

The demo loads 156 weeks of synthetic data for Tallyo, a fictional budgeting app. The KPI is new paid subscribers and there are five paid channels. Because the data is synthetic, the true effect of each channel is known, so you can see how close the model gets. You can also upload your own weekly CSV.

CSV format: date,kpi,spend_meta,spend_google_search,…,ctrl_festive_sale, one row per week, at least 26 weeks (52+ recommended). Columns starting spend_ are channels. Columns starting ctrl_ are events or controls. Download the demo data to see the shape.

Channel scorecard

ROI = incremental subscribers × margin ÷ spend. Next-dollar ROI is the slope of the response curve at the average weekly spend of the last 13 weeks. Verdicts: Scale if next-dollar ROI ≥ 1.3× target, Trim if below 0.9× target, otherwise Hold.

Budget optimiser

The guardrails limit how far each channel can move from current spend. Response curves outside the historical range are extrapolations, so test big moves before rolling them out.

Lift-test check

The true ROI used to generate the data, next to the model's estimate. Expect some misses, as real MMMs have them too. That is why lift tests matter.

Plain-English readout

Synthetic data, fictional brand (Tallyo) and fictional startup (Mixwise). Method: geometric adstock, Hill saturation (shape 1), non-negative ridge regression, coordinate grid search for carry-over and half-saturation, residual block bootstrap.
